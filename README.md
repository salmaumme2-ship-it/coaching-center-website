# Aspire Academy — Coaching Center Website

A polished, responsive one-page website template for a coaching center. Open `index.html` directly, or serve the folder with any static web server.

## Preview locally

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Customize

Search and replace the placeholder brand name, contact details, address, course names, faculty profiles, results, and image URLs in `index.html`. The core color palette is defined as CSS custom properties at the top of `styles.css`.
